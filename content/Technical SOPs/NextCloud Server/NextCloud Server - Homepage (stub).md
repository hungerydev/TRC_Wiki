**The NextCloud Server is home to TRC's instance of NextCloud, an open source Dropbox alternative. This is where all our data for the church lives, from meeting notes to sermon slides and everything in between.**

The server is running Ubuntu, and can be accessed through SSH. See [[Using SSH to Access Computers (stub)]] for instructions on how to get into the computer. This is primarily to restart functions if things break, which, barring a power outage, shouldn't happen.
# Server Functions
**The following are all the things the NextCloud server is directly responsible for:**

- [[NextCloud - Homepage (stub)|Nextcloud]] - The actual instance of NextCloud
- [[SignUp Forms - Homepage (stub)|SignUp Forms]] - A self-hosted website collating all our active sign-up forms[^1] 
- [[Switch Timer - Homepage (stub)|Switch Timer]] - A self-hosted website which is used in [[OBS - Homepage (stub)|OBS]] to regulate the time between switches
- [[Media Archives - Homepage (stub)|Media Archives]] - The home for all our audio archives for the sermons.

[^1]: This will be defunct soon as we switch to Church Center for our app
